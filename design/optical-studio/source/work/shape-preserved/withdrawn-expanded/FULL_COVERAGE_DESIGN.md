# Project DANYA — 全顔照射の改良設計

2026-09-21。後方・下側に光源を置く条件と、DLPDLCR3010EVM-G2の投射比1.2・オフセット100%を維持し、幾何光学シミュレーションで顔正面の照射率 **100%** を達成しました。起動時にこの設計を読み込みます。

## 検証結果

| 検査 | 結果 |
|---|---:|
| 顔正面、0.25 mm間隔 | 312,758 / 312,758点が照射 |
| 元の顔の正面領域との比較 | 309,265点すべて保持・照射、欠落0 |
| 顔の外側の全頂点 | 88,194 / 88,194点が照射 |
| 顔の外側の全三角形の中心 | 175,000 / 175,000点が照射 |
| 顔の外形の差、元の顔との正面比較 | 最大約1.7×10⁻¹³ mm（数値誤差） |
| 投影画像内の最小輪郭余白 | 6.98% |
| 必要な画像範囲に対する画角の広がり | 短い側でも121.5% |
| 実際の反射点からミラー輪郭までの最小余白 | 1.55 mm |
| 顔までの総光路長 | 約363–440 mm |
| ミラー／光学エンジン概形とシェルの交差 | なし |
| 各シェルの開いた辺・非多様体辺・非隣接面の自己交差 | 0 |
| 2部品の外側接合輪郭 | 1,386頂点が座標完全一致 |

照射率は「顔正面の対象領域に光が届く割合」なので上限は100%です。121.5%は、顔が占める画像UV範囲に対する投影画角の寸法比です。有限サイズのミラーも判定しており、その端には別途1.55 mm以上の余白があります。投影画像全体の光の利用効率とは異なります。

未照射点を集計から除外せず、頭部の遮蔽も有効なまま検証しました。内部表示の断面は表示だけです。顔の内壁を何度も横切る光路は、引き続き遮蔽として扱います。アプリは2 mm格子で再計算し、全点が合格したときだけ100.0%を表示します。

## 保存した位置

座標は +Xが顔の前方、Yが左右、+Zが上。1座標単位＝1 mmです。回転はThree.jsのXYZ規約です。Blenderファイルには変換済みの姿勢を保存しています。

| 部品 | X / Y / Z (mm) | RX / RY / RZ (度) |
|---|---|---|
| プロジェクターのレンズ中心 | −70 / 0 / −125 | 13.22558 / −4.13007 / 0.96971 |
| ミラーの反射面中心 | −80.49354 / −0.03607 / 144.46850 | −180 / 47.12110 / −90 |

ミラーは**約107.55 ×169.99 mmの輪郭に合わせた凸多角形**、厚さ1.5 mmです。外接する長方形をそのまま使うと角が干渉するため、保存した輪郭を使ってください。JSONには丸め前の位置・角度・80点の輪郭を記録しています。

レンズはシェル最下部より約163 mm下にあり、後方の首・胴体側に保持する配置です。光学エンジンはさらに下へ延びるので、頭の中だけで完結する配置ではありません。

## 形状の変更

- 不透明な後頭部を後方へ拡大。後方X方向は最大1.8倍、左右は後方部分で最大1.15倍にしました。顔と合わせた頭部の外接寸法は約 **261.5 mm（前後）×166.1 mm（左右）×204.2 mm（高さ）** です。
- 首の後方開口を広げ、下側の後部を最大45 mm後ろへ移動。上側へ滑らかに変化させ、投光経路を空けました。
- 不透明な頭部が顔の縁を裏打ちしていた接合位置を、反射後の光の方向に沿って変更しました。外側の接合輪郭は一致し、別々の2部品のままです。
- 顔の外面を維持し、内面を仮想光源からの放射方向に再構成。外側の点を仮想光源方向へ0.4%縮めた内面を使用し、途中で別の内壁を横切る光路を解消しました。
- 接合内面の三角形を光路に沿って分割し直し、接線上の数値的な接触を避けるため内側に最大0.005 mmの逃げを加えました。これは製造用の公差設定ではありません。

顔の壁厚は一定ではありません。対応する面の法線方向の厚み概算は中央値約1.14 mm、最小約0.10 mmです。今回のSTLは光学配置を検討する形状案であり、製造時の肉厚、材質、取付部、公差はこの光学モデルとは別に決める必要があります。

## ファイルと操作

- `Start DANYA.command`：起動。ブラウザーは `http://127.0.0.1:8769/`。
- `recommended-layout.json`：全顔照射の推奨位置と形状の指定。画面の「全顔照射の改良設計を読み込む」で復元できます。
- `DANYA-full-coverage.blend`：改良した2部品と、ミラー・光学エンジンの配置参照。
- `assets/full-coverage-v1/DANYA-face-full-coverage.stl`：改良した顔。
- `assets/full-coverage-v1/DANYA-head-full-coverage.stl`：改良した後頭部。
- `assets/full-coverage-v1/DANYA-mirror-local.stl`：ミラー形状、局所座標。
- `full-coverage-validation.json`：検査点数、形状チェック、配置、ファイルのSHA-256。
- `full-coverage-design.json`：形状変更と光学構成の設計パラメーター。

「初期配置に戻す」で元の形状へ切り替えられます。元のSTLと以前のBlenderファイルは保持しています。以前の78%台の配置は `previous-rear-layout.json` に保存しました。

保存したメッシュを再検証するには、このフォルダーで既存のNode.jsを使って次を実行します。追加インストールは不要です。

```bash
node validate-full-coverage.mjs 0.25
node --test tests/optics.test.js
```

## モデルの範囲

オーキャンv2のライブ描画を使用し、頭部は不透明、顔は拡散透過面として表示します。単一の表面鏡とピンホール投影の幾何検証です。実機での全域の合焦、レンズ収差、屈折、散乱、明るさの均一性、投影映像の顔形状へのキャリブレーションは保証していません。

エンジン概形は約56.97×21×80.35 mmです。評価基板、放熱、配線、固定具、レンズ位置の実機CADは未反映です。

光学仕様は [TI製品ページ](https://www.ti.com/tool/DLPDLCR3010EVM-G2) と [TIユーザーガイド DLPU058A / Table 1](https://www.ti.com/lit/ug/dlpu058a/dlpu058a.pdf) に基づきます。投射比やオフセットを広げて100%にしたものではありません。
