PROJECT DANYA / SYSTEM STUDY

頭部に合わせた首の再設計

ST3215の12V版3台＋軸受支持＋3:1ベルト減速の候補。実寸プロジェクタ・鏡・頭を一体で動かします。

首の中心と回転軸を修正した再設計案です。旧モーター配置の検証は失効しています。鏡の見積、連続トルク、支持部の穴・締結、ベルト／配線／外装との干渉は未確定。発注・本番印刷の完成データではありません。

首の位置を修正

元の頭部から首の断面を抽出。胴体側の首中心を約52.8mm後ろへ合わせ、胸からその断面につながる形に変更しました。頭・顔の外形と胸の下部は維持しています。

首中心 X / Y−22.02 / 0.35mm
頭側の接続断面110.49 × 119.75mm
回転中心首断面の中心へ変更
暫定表示範囲左右±15°、他±5°

従来の左右±45°・うなずき±20°・傾き±15°では、新しい軸に対してプロジェクタが胸へ干渉します。可動範囲を確定したわけではありません。広い可動域と収納の両立は引き続き再設計が必要です。

小角度27姿勢の簡易検査ではプロジェクタ頂点が胸の内側に残ります。柔軟カバーは接続を確認するための変形表示で、材料・しわ・光路・機構干渉は未検証です。以前の「頭と胸の余裕8.43mm」「モーター27姿勢合格」は新設計には適用しません。
