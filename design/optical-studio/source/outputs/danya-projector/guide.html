DANYA Projection Studio

画像・動画・共有ウィンドウを、顔スクリーンに合わせて変形して出力するアプリです。通常起動時に3Dモデルを読み込みません。

画像を直接つかんで編集

目・口・鼻・眉を直接ドラッグして移動します。点以外の額や頬、背景をドラッグすると顔全体が移動します。ホイールはカーソルの位置を中心に拡大・縮小します。選択した部位は下の「部位＋／−」で大きさを変更できます。「元に戻す」で一つ前へ戻り、「詳細設定」で従来の数値・色調整を開きます。全画面編集でも同じ操作です。

1. 起動と接続

Start-DANYA.command をダブルクリックし、開いた画面を使用します。Python 3 と WebGL 2 対応のChrome / Edgeが必要です。プロジェクタはPCの拡張ディスプレイとして接続します。

横画面と顔の大きさ

画面上部の横長プレビューに、顔全体の大きさ・横位置・縦位置のスライダーを配置しました。大きさは25〜250%です。部位の移動設定とは独立しています。

2. 映像と基準点

  1. 参考画像は静止画です。動く映像には動画ファイルを読み込むか、「ウィンドウを共有」で顔映像を表示しているウィンドウを指定します。動画・画像はブラウザー内に保存されます。
  2. 「向き・切り抜き」で顔の向きと範囲を合わせます。新しい動画・画像を読み込むと向きと切り抜きは全体に戻ります。
  3. 「元画像の基準点を指定」を押し、点を両目・両眉・鼻・口の中心に置きます。範囲は、その部位を覆う程度に調整します。自動追跡ではありません。頭の位置が大きく動く動画は、元映像側で顔を固定してください。
  4. 基準点モードを解除し、各部位をドラッグまたは数値で移動・拡大縮小・回転します。部位を独立した画像層として移動し、元の位置は周囲の色から補完、移動先は境界をぼかして合成します。「移動する範囲」を部位全体に合わせてください。補助点では頬・顎などを追加調整できます。

3. 実物に合わせる

「投影出力」で四隅を合わせ、実物を見ながら微調整します。v5頭部の理論初期値は、既存設計の大小鏡光路から事前計算した2Dデータです。実際の鏡角度、取り付け、光学オフセットの誤差を測定した結果ではありません。古い設計との対応が不明な場合は手動調整を使用してください。

四隅は全体位置・台形の調整、部位と補助点は顔の局所調整です。暗い部分に光が物理的に届いていない場合や焦点が合わない場合は、画像変形では解決できません。

4. 肌と輪郭

露出・ガンマ・彩度・肌色混合を調整できます。「肌を中心に補正」は色と部位の基準点による近似マスクです。色が不自然な場合は解除し、全体補正で合わせてください。外周マスクで顔の周囲を黒にできます。

全画面で編集・90度回転

「フルスクリーン」（F / Eキー）では編集点と操作パネルを残して全画面にします。顔の点をドラッグし、右側のパネルで微調整できます。画面上部の ↶90° / ↷90° で向きを切り替えます（Rキーは時計回り）。入力画像・切り抜き・基準点は維持され、投影出力にも同じ回転を反映します。拡大しすぎて画面外に出る場合は顔全体の大きさを下げてください。Escまたは「全画面編集を終了」で戻ります。

5. 全画面で投影

「投影ウィンドウを開く」で独立出力を開き、プロジェクタ側ディスプレイへ移動して F またはフルスクリーンボタンを押します。フルスクリーン中はボタンや基準点を出しません。Esc で解除、B で暗転します。出力画面は独立して動画再生するため、調整画面が背後になっても出力できます。

1280×720はプロジェクタの標準出力です。PC側の解像度も合わせ、OSとプロジェクタの余分な拡大・台形補正を避けます。

6. 保存と軽量運用

有効な補正設定は自動保存します。「設定を書き出す」でJSONをバックアップしてください。画像・動画の保存は同じブラウザー内に限ります。別PCへ移す場合は設定JSONと元動画を両方持っていきます。

オーキャン配信接続には、従来の配信アプリの起動が必要です。その入力を録画してWebMで保存すれば、次回から動画だけで動かせます。録画は変形前・切り抜き後なので、再入力時は回転0°・切り抜き全体を使用します。

精度と検証の範囲

部位は独立移動、肌の補完は周辺サンプルによる近似です。AIによる新しい肌テクスチャの生成ではないため、大移動や強い陰影では補完跡が残ることがあります。補助点の変形はThin Plate Spline、GPU参照マップは最大513×513、理論光路データは16bit UVです。これらは内部計算の精細さであり、実機の位置精度の保証値ではありません。変形の折り返しを計算格子上で検出した場合は適用を拒否し、最後の正常な表示を維持します。

実物への投影・材料透過・焦点・鏡の二重反射は別途、実機で確認してください。プログラムは眼や口の内容を新しく生成するものではなく、用意した映像を変形します。

編集画面のFキーも編集可能な全画面です。全画面中も、顔・部位のドラッグとホイール拡大縮小が使えます。操作表示のない投影には、別の「投影ウィンドウ」を使います。
