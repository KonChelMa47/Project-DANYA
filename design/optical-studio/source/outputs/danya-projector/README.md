# DANYA Projection Studio

Start-DANYA.command をダブルクリックして起動してください。
URL: http://127.0.0.1:8771/
操作ガイド: http://127.0.0.1:8771/guide.html

Python 3、WebGL 2対応のChrome / Edgeが必要です。追加のPython / npmパッケージは不要です。
手動起動: `python3 server.py`

- 目・眉・鼻・口の形を保った独立移動／拡大率／回転、元の位置の肌補完と境界合成
- 最大8個の補助点、4隅の投影位置補正
- 肌色・露出・ガンマ・彩度、輪郭マスク
- 動画・画像・画面共有、独立した全画面投影、暗転
- 自動保存、設定JSONの入出力、入力映像のWebM録画
- STL / GLB / Three.jsの実行時読み込みなし

最初の映像はオーキャンの参考静止画像です。動画や画面共有を選ぶと動く映像を投影します。顔の追跡・表情生成はしません。動く口や眉は元の動画の内容を変形します。設定ファイルに映像本体は含まれません。

実機と設計の誤差は、投影を見ながら校正してください。v5光路補正は設計由来の初期値であり、実機測定値ではありません。遮蔽、焦点、二重反射をソフトだけで解消するものではありません。
