# 実測による投影範囲の確認

ユーザー実測：レンズ前端から200 mmの位置で、全白画像は約167.5 × 94 mm。ピントが合う。

- 見かけの投射比：200 / 167.5 = 約1.194。
- 縦横比：167.5 / 94 = 約1.782。16:9（約1.778）と整合。
- 公称TR1.2・16:9からの予測：166.67 × 93.75 mm。実測との差は幅+0.83 mm（約0.50%）、高さ+0.25 mm（約0.27%）。測定は概数なので有意差とは判断しない。
- 200 mmでピントが合うことは実機で確認済み。ただし他の距離の合焦、被写界深度、折り返し後の凸鏡を含む合焦は未確認。

現アプリの公称TR1.2はこの実測と整合するため保持する。約値の1点測定だけで既存マスクを無効にする微調整は行わない。別の感度検査では見かけのTR1.194と合焦平面200 mmを用い、瞳径を仮定して再計算する。

1点の全画像寸法からは、光学基準点のずれと投射比を独立に分離できない。また、レンズの出口瞳の径・位置、1画素の光束の太さ、光量、垂直オフセットはこの測定では決まらない。今回の測定をレンズ開口の校正として扱わない。

したがって「プロジェクタ全画面の広がりが公称と一致し、200 mmで合焦できる」ことを確認した段階。現在の細い折り返し光路が実機で成立したことを意味しない。
