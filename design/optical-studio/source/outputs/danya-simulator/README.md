## 起動

このフォルダーの `Start DANYA.command` をダブルクリックします。ローカルサーバーとオーキャンv2の描画プロセスを起動し、ブラウザーで `http://127.0.0.1:8769` を開きます。終了は起動したターミナルで Control-C。初回にmacOSが実行確認を表示する場合は、ターミナルから次を実行してください。

```bash
cd "/Users/daniilmalchenko/Documents/Codex/2026-09-21/bl/outputs/danya-simulator"
/usr/bin/python3 server.py
```

外部への公開は行わず、127.0.0.1 のみに接続を受け付けます。ブラウザーはWebGL対応のChromeまたはSafariを使用してください。

## 操作

1. 「プロジェクター」「ミラー」「第1折り返し鏡」「折り返し鏡」で移動対象を選び、XYZ欄か3Dの軸ハンドルで位置を変更します。プロジェクター位置は**機械的レンズ前縁中心（出射瞳は実測が必要）**、ミラー位置は**反射面の中心**です。
2. 「回転」かRX/RY/RZで角度を変更します。角度はThree.jsのXYZ Euler規約、単位は度です。「画像中心をミラー中心に向ける」は投射画像中心を狙う補助操作です。オフセットがあるため、機械的な光軸とは異なります。
3. 「直線に沿って移動」はワールドX/Y/Zまたは対象の局所Z軸に拘束します。局所Zはレンズの光軸／ミラーの表面法線です。「現在位置を…原点にする」でスライダーの基準を更新します。スライダー自体は±100 mm、数値欄は±3000 mmです。
4. ミラーの幅・高さと反射率、顔の拡散透過率を変更できます。ミラーは片面反射です。金色の矢印側が反射面になります。
5. 「外側から見る」で不透明な頭と投影された顔を確認します。「内部・光路」は頭を片側断面表示にします。**断面表示は光学計算に影響しません。** 緑系の光線は顔へ到達、橙はシェルで遮蔽、青灰色は外れた光線です。代表光線のみ描画します。
6. 映像はオーキャンv2、グリッド、ローカル動画から選べます。動画はブラウザー内だけで再生し、サーバーへアップロードしません。回転時は全体が入るように縮小し、余白を黒にします。ミラーと背面投影による画像方向は光学計算に従うため、必要なら映像の左右反転・回転で調整してください。
7. 「設定を書き出す」でJSONに保存。「読み込む」で復元できます。ローカル動画本体と視点位置はJSONに含みません。動画を使用する場合は再選択します。

## 光学モデルと仕様

TIの [DLPDLCR3010EVM-G2 製品ページ](https://www.ti.com/tool/DLPDLCR3010EVM-G2) の解像度1280 × 720、公称光束220 lmを表示します。[TIユーザーガイド DLPU058A / Table 1](https://www.ti.com/lit/ug/dlpu058a/dlpu058a.pdf) に基づき投射比1.2、オフセット100%、フォーカス範囲5–50 inch（127–1270 mm）を初期値にしています。ガイドにはLED電流条件付き235 lmも記載されています。

- 光軸距離 `d` の平面で画像幅 `d / 1.2`、高さ `幅 × 9/16`。100%オフセットを「画像下端が光軸上」と解釈します。実機の取り付け方向・オフセット定義との一致は実測で校正してください。投射比・オフセットは変更可能です。
- 画像画素からの光線と、有限幅・有限高さの鏡面の交差を計算。反射は `r = d - 2(d·n)n`。面の裏側から入射する光は反射しません。
- 顔の各頂点に対して、平面鏡では虚像プロジェクター、凸球面鏡では球面上の反射条件を数値的に解いて逆投影します。両方の光路区間を完全なシェルメッシュに対してBVH判定し、最後に連続して横切る顔の材料層のみを拡散透過として扱います。別の顔の部分を先に貫通する経路は遮蔽します。
- 遮蔽の表示は頂点で計算した結果を三角形内で補間します。交差の数値許容差は約0.08–0.10 mmです。細い影の境界はこの離散化の影響を受けます。
- 指標「顔正面の照射率」は正面から見える顔を2 mm格子でサンプリングした照射割合です。曲面の実表面積ではなく正面への投影面積に対応します。その下の「画像光線の到達率」は41 × 23本の画素光線が顔へ届く割合で、顔の照射率とは別の値です。 光路長はレンズ→鏡→顔内面の合計です。
- 顔の見え方は動画色×仮定した反射率・透過率×表示ゲインによる相対プレビューです。ルーメンを実測輝度に変換していません。逆二乗照度、入射角依存、散乱分布、焦点ぼけ、レンズ歪み、収差、回折、複数回反射は未モデル化です。フォーカス範囲内の表示は、曲面全体の合焦を保証しません。

## オーキャンv2接続

`~/Documents/Project-DANYA/open-campus-demo-v2/robot_projection/robot_projection.py` を、そのプロジェクトの既存 `.venv/bin/python` で読み込みます。保存済み `camera_state.json` と `semantic_face_state.json` を読み、実際の描画フレームを取り出します。GUIの編集用マークを除いた描画を使います。元のプロジェクトファイルには書き込みません。音声・会話サーバーの起動や画面全体のキャプチャはしません。

出力は `runtime/frame.jpg` と `runtime/feed.json`、ログは `runtime/avatar.log`。更新周期は描画負荷に依存します。ソース停止時は最後のフレームを保持し、画面に停止状態を明示します。

別の場所のプロジェクトを使う場合:

```bash
/usr/bin/python3 server.py --project "/path/to/Project-DANYA"
```

映像なしで起動する場合（グリッド・動画ファイルは使用可能）:

```bash
/usr/bin/python3 server.py --no-avatar
```

JavaScript: Three.js 0.180.0 / three-mesh-bvh 0.9.2。Pythonサーバーは標準ライブラリのみ。オーキャンv2ブリッジは既存のProject-DANYA環境を使用します。

```bash
node --test tests/*.test.js
```

単一反射、投射比・オフセット、逆投影、有限・片面ミラー、各区間の遮蔽、顔の最終層の透過、軸拘束、設定の検証をテストします。実機との差は投射比、オフセット、スケール、取り付け角度と材質を測定して校正してください。
