# 外形保持・コンパクトな全顔照射案

元の人間に近い顔・後頭部の外形を拡大・変形せず、プロジェクターを後方下部に置く配置を保存しました。起動時と「外形を保った配置を読み込む」で適用されます。外形を拡大した旧案は撤回済みです。

## 配置と大きさ

座標は mm、+X=顔前方、Y=左右、+Z=上。回転は Three.js XYZ Euler、度です。

| 部品 | 中心 XYZ | 回転 RX / RY / RZ |
|---|---|---|
| プロジェクターレンズ | -55 / 0 / -15 | 13.226193 / 5.317995 / -1.253357 |
| 凸球面鏡 | -40 / 0 / 110 | -180 / 48.950395 / -90 |

ミラーは **曲率半径 R60 mm、開口約54.07 ×43.65 mm、厚さ1.5 mmの専用凸球面鏡**です。STLの縁形状に沿う前面反射鏡を想定します。平面鏡に置き換えるとこの結果にはなりません。厳密な値・開口輪郭は `recommended-layout.json` にあります。

シェル、ミラー、光学エンジン概形を合わせた外接寸法は **高さ343.82 ×幅144.60 ×奥行181.83 mm**。Furhat公称410 ×270 ×240 mmより小さい寸法範囲ですが、こちらには基板・冷却・配線・取付金具・外装台座を含みません。[Furhat公式仕様](https://www.furhatrobotics.com/furhat-robot)

## 外形と内部加工

- 顔外面85,642頂点・169,900三角形は元の座標・形状のまま。内面だけを反射光路に沿って作り直し、法線方向の厚さは概ね1.1 mm（頂点での推定最小0.795 mm）。
- 後頭部の外面111,447頂点は元データと完全一致。6方向34,452本の外形比較でも差は最大2.28e-13 mm。
- 後頭部の内部に、鏡から顔へ向かう光を遮らない空間を切り出しました。切り出しの鏡側には12%の幅方向余白を付け、顔側では元の輪郭に接続します。
- 顔・後頭部は別々の2部品。外側の接合輪郭1,382頂点が完全一致し、設計上の外側の隙間はゼロです。製造公差や取り外し方法は別途設計が必要です。
- 元の `assets/DANYA-head.stl` と `assets/DANYA-face.stl` は保存したままです。内部加工版は `assets/full-coverage-v1/`、配置付きBlenderは `DANYA-full-coverage.blend`。

## 照射の検証

| 検証 | 結果 |
|---|---|
| 顔正面0.25 mm格子 | **309,265 /309,265点、100%** |
| 顔外面の全頂点＋全三角形中心 | **255,542 /255,542点、100%** |
| 元の顔の投影対象が消失 | 0点 |
| 顔外面の前後位置変化 | 0 mm |
| 後頭部による新たな正面遮蔽 | 0点 |
| 鏡・エンジン概形と各シェルの三角形交差 | なし |
| 2部品の開放辺・非多様体辺 | 各0 |

照射率は最大100%です。「100%以上」の余白は、必要な画像UV範囲に対して投射画像の縦横寸法が最小 **117.97%** あることで確保しています。これは面積の照射率ではありません。ミラー端までの最小余白は2 mm。UIの「輪郭外の画角余裕」は最寄り画像端までのUV余白を両側換算する別指標です。

有限開口の凸球面鏡上で反射条件を解き、レンズ→鏡、鏡→顔の両区間を実メッシュで遮蔽判定しています。後頭部を透過させたり、未照射点を母数から除いたりしていません。最後の連続した顔の材料層だけを透過させます。上記は離散サンプルと約0.08–0.10 mmの交差許容差による幾何学的検証で、連続面全点の数学的証明ではありません。

## 実機に向けた未検証事項

TI指定の投射比1.2、オフセット100%、1280×720を維持しています。[TIユーザーガイド](https://www.ti.com/lit/ug/dlpu058a/dlpu058a.pdf)

凸面鏡には光学的な屈折力があるため、単純な総光路長だけではピントを判定できません。実レンズと専用鏡での合焦、非点収差、明るさ、映像の歪み補正は未検証です。オーキャンv2のライブ表示は幾何学的プレビューです。代表画素光線の約83%が小型鏡を外れるため、投射光の利用効率と実際の顔の明るさも確認が必要です。

鏡STLは曲面の形状参考で、通常の3Dプリント面をそのまま光学鏡として使えるわけではありません。エンジン箱は約56.97 ×21 ×80.35 mmの概形で、EVM全体の実装・冷却・支持構造は未設計です。

後頭部のBoolean加工面には数値検査で微小な三角形交差8組（最長0.00281 mm）が残ります。両シェルは閉じた各1成分ですが、製造確定版としてはこの内部メッシュの整理と肉厚・公差確認が必要です。外形と照射の結果には上記の検証値を使用しています。

## 再検証

このフォルダーで `node validation-exterior-preserved/verify.mjs 0.25` を実行すると、配布した加工済みメッシュと設定を読み込み、照射・元の顔の保持・概形干渉を再計算します。原本検査結果は `validation-exterior-preserved/` に保存しています。光学単体テストは `node --test tests/*.test.js`（11件合格）。
