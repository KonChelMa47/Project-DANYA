# 後頭部側・低位置の取り付け候補

シミュレーターの「後方取り付けの推奨配置を読み込む」で適用できます。設定は `recommended-layout.json`。

| 部品 | 中心位置 X, Y, Z（mm） | RX, RY, RZ（度） |
|---|---|---|
| プロジェクターのレンズ | -40.00, -1.87, 0.47 | 10.96, 1.12, 0.31 |
| ミラー反射面 | -22.52, 0.86, 178.53 | 178.70, 31.17, -87.50 |

ミラー寸法は **80.9 × 110.9 mm**。Xの負方向が後頭部側、Zが上。角度はアプリのXYZ Euler規約です。1座標単位=1 mmというモデルの仮定を使用しています。

初期レンズ位置 (16, 0, 20) から後ろへ56 mm、下へ19.53 mm移動しています。首開口の最低位置Z≈38.28 mmよりレンズが約37.81 mm下にあり、光学エンジンはその下に延びます。

## 照射結果

- 顔正面の照射率：**78.44%**（0.5 mm格子、77,322点中60,654点）。
- 初期配置は約66.7%（2 mm格子）。アプリの通常表示は2 mm格子なので約78.7%と表示されます。
- 総光路長：検証点で約235–321 mm。
- ミラーの有効範囲から外れる点：約10.6%。
- 投影画像の範囲から外れる点：約10.3%。
- 反射後に頭部に遮られる点：約0.7%。

**全面照射には未達です。額と外周に未照射が残ります。** 画像光線の利用率とは区別して評価しています。今回の探索で100%を満たす配置は見つかりませんでしたが、不可能と証明したものではありません。

## 取り付けの確認範囲

- 後頭部側の低いレンズ位置を条件として探索。
- ミラー寸法を調整し、シェルに食い込む候補を除外。
- 最終ミラーは幅・高さに各2 mmを加えた厚さ3.5 mmの箱でも、顔・後頭部に交差しません。
- 表示中の光学エンジン概形（56.97 × 21 × 80.35 mm）も顔・後頭部に交差しません。
- 評価基板全体、放熱、配線、取付金具はこの干渉確認に含みません。

初期の110 × 115 mmの矩形ミラーをそのまま移動した候補は、照射率が高くてもシェルとの干渉が残ったため採用していません。

## 再検証

このフォルダーで次を実行します。JavaScript依存関係はインストール済みです。

```bash
node scripts/diagnose-layout.mjs recommended-layout.json 0.5
node scripts/verify-rear-layout.mjs
node --test tests/*.test.js
```

`rear-layout-validation.json` に最終値と干渉判定を記録しています。
