# 公開資料による追加調査と、頭部を含む有限瞳の検査

測定を待たずに行った追加評価です。実機のレンズ処方を取得したわけではありません。

## 搭載エンジンと資料

TIのG2組立図TIDRUZ8では、エンジンは `900-0021-00 H6 / ePROTECH PT3 720P DISPLAY ENGINE` と特定されています。[TI組立図](https://www.ti.com.cn/lit/pdf/TIDRUZ8)

G2の外付けレンズに関するTIの回答では、光学設計についてAnhua Optoelectronicsに問い合わせるよう案内されています。[TI E2E回答](https://e2e.ti.com/support/dlp-products-group/dlp/f/dlp-products-forum/762368/dlpdlcr3010evm-g2-add-extra-external-lens-on-dlpdlcr3010evm-g2-projector-to-minimize-the-projection-area)

Anhuaの公開カタログではM6SF(LC)などのレンズ仕様が見つかりますが、青色単色・オフセット0%など搭載G2と異なる仕様です。そのF値や作動距離をG2の値として代用しません。[メーカーの別機種ページ](https://anhuaoe.com/en/demokit/info.aspx?itemid=3127)

調べた公開資料からは、搭載G2レンズの出口瞳径・出口瞳位置・レンズ処方は特定できませんでした。未公開だと断定しているわけではありません。確認できた型番、投射比、オフセット、全画面光量と、不明なレンズ値を区別しています。

## 追加した数値検査

前回は鏡だけの感度検査でした。今回は頭部、顔、本体一式、鏡の裏面も入れ、毎回最も近い面を選んで最大8反射まで追跡しました。TI公式CADとユーザー提供Tripoモデルの両方で実行しました。

仮定は、機械的レンズ前端に直径0/2/4/6/8 mmの円形出口瞳があり、直進すれば127/250/500 mmの平面に合焦する理想光束です。顔外面の86点に対応する画素を選び、各画素について瞳内128点を面積均等サンプリングしました。これらは前回のマスクで消されない画素です。材料散乱・レンズ内部反射・回折は含みません。

下表は公式CAD、合焦面250 mmという仮定での例です。

|仮定した出口瞳径|正規経路で顔へ届いた光線の割合|別経路で顔へ届いた光線|
|---|---|---|
|0 mm|98.84%|0 / 86|
|2 mm|55.92%|0 / 11008|
|4 mm|27.41%|1 / 11008|
|6 mm|15.25%|1 / 11008|
|8 mm|9.04%|0 / 11008|

割合は、この86画素の仮想光束をサンプリングした光線数の割合です。**顔の照射面積でも、実測効率でも、全映像の光束の重み付き効率でもありません。前回の5.4 lmにこの割合を掛けて実機の明るさとみなすこともできません。**

点光源ケースでも85/86点しか順方向で顔に分類されませんでした。外縁付近を含む対象点、顔の内面への最初の到達、頭との接合部の判定は、前回の外面目標点への逆算検査と異なります。この差も含め、旧100%という表示を物理的な合格と扱いません。

直径4/6 mmのケースではマスクで通していた画素の周辺光線が別経路から顔に到達しました。二重像の輝度・目視での見え方を確定したものではありませんが、一点光源で作ったマスクをそのまま実機の対策として保証できない追加証拠です。

## 現時点の判断

現配置を実機設計として確定しません。細い主光線だけの光路・極小の第1鏡・光路に密着した内壁・R16.5 mmの強い凸鏡を、有限光束に対して一体で再設計する必要があります。顔や後頭部の形状、プロジェクタの実寸を勝手に変更して解決したことにはしません。

公開資料と複数仮定による評価は進められますが、「搭載実機で再現される光束」の最終校正には、その機種のレンズデータか実測が必要です。実測は現在の追加調査を進める前提条件にはしていません。
