# コンパクト収納と全顔照射：検証候補 v2

2026-09-22。**実機での要求達成とはまだ判定していません。** 最新候補をシミュレーターの初期配置に反映しました。DLPDLCR3010EVM-G2一式、135 × 75 mmの実測底面、元の顔と後頭部の一様110%外形を維持しています。

後頭部の外面は全三角形の座標が元データと完全に一致します。内面を光線方向へ作り直し、接合部の内側に0.6 mmの斜面を設けました。顔は元の厚み付き形状を維持し、2部品間の材質の重なりはBlenderの交差演算で0 mm³でした。頭部メッシュの開いた辺・不正な辺接続はありません。

映像の一部分をマスクで切り出す処理を置き換えました。映像の全範囲を顔面の正面座標に割り当て、投影用の変形画像を作っています。ライブ映像は元の横向き描画に合わせ270°回転します。目・鼻・口の厳密な位置合わせは今後の校正対象です。

これらは**離散点・理想光学モデルの検査**です。出口瞳の径・位置、光量分布、曲面反射後の実際の合焦、鏡の製作精度、固定具・配線・放熱の余裕は未確定です。内壁は公称1 mmを基準にしていますが、斜めの部位では移動量を制限しており、実際の最小肉厚と製造性を別途検査する必要があります。STLは試作検討用で、製造確定版ではありません。

次は有限光束に対する投影マスク・遮光構造を検査し、映像の境界余裕、顔の位置合わせ、収納の取り付け条件を詰めます。前の[平面鏡だけの比較](FLAT_MIRROR_REDESIGN.md)は不採用の記録です。

## 追加した遮光片の検査

レンズ前端を基準とする1 mm前方に、厚さ0.3 mm、最大約12 mmの斜めの遮光片を追加しました。プロジェクタと一緒に移動します。元映像の画素を削るだけの案では436 / 5,837点に未照射が生じたため、不採用です。

現在の変形画像が使う画素を模擬した検査では、遮光片なしの仮の直径8 mm光束に1,644本の別経路を検出しました。遮光片追加後、同じ383,216本の検査で別経路は0本でした。別の64瞳点・画素間隔4の383,104本の検査でも0本でした。逆向きの5,837点検査では未照射は0点、最も少ない場所で32本中6本が通過しました。これは照射面積や実測の光量を直接表す比率ではありません。

追加部品は本体・鏡・シェルと干渉せず、検査した0.3 mm以上の隙間を確保しています。実機レンズへの取り付け、出口瞳の実値、明るさへの影響は未確認です。これらの数値は出口瞳をレンズ前端に置き、合焦面165 mmと仮定した離散光線の結果です。実機で二重像が出ない保証ではありません。

別作業で首元の内面75頂点を補強する案も作成し、全255,542点の代表光線と収納検査を通過しました。この補強案はまだ公開STLへ適用していません。
