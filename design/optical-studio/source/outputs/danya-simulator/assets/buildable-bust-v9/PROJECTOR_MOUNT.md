# プロジェクタ底面受け — v9試作候補

ユーザー実測の135 × 75 mmの長方形底面で位置決めする。TripoAIモデルの底面ねじ位置は採用しない。レンズの位置・向きは従来の光学配置を維持。

## 寸法と固定方法

- 内寸135.8 × 75.8 mm、片側すきま0.4 mm。印刷精度による調整前。
- トレー底厚5 mm、底面との通気すきま3 mm。2か所の大きな開口を設ける。
- 4点の支持面に底板を載せ、4個の着脱式押さえをシリコーン当て材越しに底板の縁へ当てる。
- 押さえ用M3 × 20ボルト4本、M3平ワッシャー4枚、M3普通ナット4個。図中のねじ山は省略。
- 支持フレーム用にはトレー裏側に別のM3ナット4個を配置。プロジェクタ本体には穴加工しない。このフレーム自体は未完成。
- 底板厚3.97 mmはTI CADからの仮値。シリコーン厚1 mm、組立隙間0.53 mmも仮値で、保持力や圧縮量の実証値ではない。

## 組立順

1. トレー裏側へフレーム用ナットを入れ、完成後のフレームで保持する。
2. プロジェクタの底面を支持面に載せる。縁の出っ張りを逃がす切欠きの向きを合わせる。
3. 当て材・押さえを取り付け、4か所のM3締結で抜けを防ぐ。底板厚の実測に合わせ、当て材厚と押さえ高さを調整してから締める。
4. 取り外す場合は押さえを外して持ち上げる。無理にはめ込む方式ではない。

## 現在の検査範囲

25部品はそれぞれ有効な単一CADソリッド。現行モーター向きで27姿勢を調べた新規固定具検査では、トレーと当て材の意図したプロジェクタ接触以外に接触は報告されていない。トレー本体の接触位置も別途調査し、底面の4点支持部に一致することを確認した。

検査は三角形表面の交差とサンプル光線を対象とする。支持フレームが存在しない状態の結果であり、完成機構の無干渉・強度・全光束通過を保証しない。同一固定具内の接触は全体検査から除外している。HDMI/DCプラグとケーブルの差し込み・曲げ空間、実機底面寸法公差、放熱、振動、姿勢変更時の保持力は検証前。
