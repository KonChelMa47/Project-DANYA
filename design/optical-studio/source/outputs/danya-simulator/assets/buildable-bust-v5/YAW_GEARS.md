# 左右回転軸の歯車化

2026-09-22。ユーザーの「回転のところを歯車に」を左右回転（yaw）軸として実装。うなずき・傾きはv4のベルト方式を継続。

外周歯車付きの中空キャリア96Tと、サーボ側20T小歯車を使用する試作案。モジュール1、圧力角20度、歯幅6mm、軸間58mm、減速比4.8。大歯車外径98mm／内径82mm、小歯車外径22mm。左右±30度に対してサーボ±144度となる。

従来の概略150T/20T案を撤回して置換。歯形はインボリュートの離散近似、歯元は簡略な放射状つなぎでトロコイドフィレットではない。各歯車のピッチ円上の歯厚を0.1mmずつ減らし、組合せの名目歯すき0.2mmを設定。製造公差や材料収縮は未反映。

サーボ位置は軸間58mmに合わせて約3.63mm外へ移動。首の中心・外装・頭部・他の2軸の配置は維持。小歯車は逆方向に4.8倍回転する表示を実装した。

## チェック

- 小歯車1歯分の回転を181段階で比較し、歯車同士の三角形表面交差0。実接触・連続運動・荷重・歯すきの検証ではない。
- 27姿勢で、新しい歯車対プロジェクタ、および移動したサーボ対プロジェクタ・他サーボの簡易検査で交差0。
- 新しいサーボ外接箱の胴体断面余裕指標は最小11.09mm。歯車頂点の同指標は最小14.42mm。3mm半径方向壁代の楕円断面検査であり、3D最短距離・非凸容器への完全包含ではない。
- 移動したサーボも、27姿勢のサンプル主光線対外接箱+4mm検査を通過。有限瞳の投影光束の保証ではない。

## 残る詳細設計

大歯車は環状軸受と押さえで支持し、サーボ軸に頭の荷重を直接掛けない。サーボ取付台はかみ合わせ調整用の長穴を設ける方針。小歯車の5mm穴はCAD上の仮の下穴であり、ST3215へ直付けできる形状ではない。実際のサーボホーンに合う接続アダプター、ねじ・抜け止め、環状受けとフレームの固定、歯元強度、騒音・摩耗・実際の歯すき調整が必要。

[yaw-ring-96T.stl](yaw-ring-96T.stl) と [yaw-pinion-20T.stl](yaw-pinion-20T.stl) は配置・かみ合わせ検討用の試作形状。荷重を支えられる完成部品とは扱わない。追加購入・スライスは実施していない。予算上限3万円の方針を継続。
