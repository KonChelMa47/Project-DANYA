# Project DANYA：3万円以内の全体設計候補

ユーザー指定：スライス作業を保留し、全体機構を優先。承認された小型男性胸像を基準とする。既存プロジェクタ、顔、後頭部を使用。追加凸レンズなし。

## 予算
BOM-30000.csvの合計上限枠は30,000円。これは見積済み合計ではない。鏡は国内業者が1.1mm表面反射鏡のカットを扱うことを確認した段階で、5,000円で作れる保証はまだない。サーボ3個11,000円、USB制御1,500円、鏡2枚5,000円、電源・保護3,000円、軸受・伝達3,000円、配線1,500円、ねじ1,500円、送料等3,500円。既存PC／プロジェクタとそのアダプターは再利用、印刷材料代は未計上。注文・決済はしていない。

## 駆動を変更
XM430／U2D2案は予算に合わないため候補から外す。ST3215の12V版3個＋Bus Servo Adapter (A)をPCのUSBから制御する候補へ変更。7.4V版やHS版を混同しない。3kgではなく30kg·cm（約2.94Nm）はストールトルクで、連続許容トルクとして使わない。連続トルクは未確認。

荷重経路：底板 → 2個の軸受で支えるヨー軸 → 左右のピッチ支持部 → ロール支持部 → 一体の光学フレーム。頭とプロジェクタの重量は8mm軸と608ZZ軸受へ流し、サーボはベルト経由で回す。20歯／60歯の3:1減速、2mmピッチ・180mmベルトなら中心距離は概算48.3mm。軸の間に光路を通し、横断するシャフトは置かず左右の短い軸で支持する。歯数・ベルト長・軸の締結は配置とトルクの検証後に確定する。

## 一体で動く光学フレーム
頭・主鏡・小鏡・プロジェクタを同じ剛体として動かし、相互位置を保持する。現行投影位置と元の頭の形を保つ。外装形状は拡大せず前方へ15mm移す候補、回転中心は[35,0,-65]mm。サンプル45姿勢・実寸プロジェクタ凸包で最悪の半径方向余裕は約9.37mm。ただし3D最短距離でも連続動作合格でもない。鏡・駆動部・配線は別途検証が必要。

## 硬い首は廃止して柔軟なカバーへ
現在の硬い襟は頭に干渉する。胸の剛体部分をZ=-20mm以下、上部Z=-20〜38mmを柔軟カバーとする候補。新回転中心で頭・顔全頂点を検査すると、左右±45°／ピッチ±20°／ロール±15°全域で最低Zは保守的に-11.565mm以上。したがってZ=-20mm以下の硬い胸部と頭・顔は上下方向に8.435mm以上離れる。これは柔軟カバーの変形や内部の梁を保証するものではない。柔軟カバーは荷重を受けない。

## 鏡
主鏡は約129.846×155.403mmの予定有効領域。1.1mm厚の表面反射鏡は、反射面の位置を変えずにモデル上で頭内壁まで約0.829mm、顔まで約17.694mm。これは名目面間距離のみ。厚み公差、輪郭加工、フレーム保持、位置調整余裕を入れた合格ではない。裏面3点支持と押さえを検討し、表面反射面を光側へ向ける。普通の裏面反射鏡へ置き換えない。小鏡は約23.828×35.185mmの有効領域。DXFは光学領域で切断線ではない。

## 配線・電源
既存プロジェクタの電源系と12Vサーボ系は分離。PCからHDMIで映像、USBでサーボ制御。背面に固定のサービスパネルを置き、内部は抜き差し用余白とストレインリリーフ、3軸をまたぐたるみを設ける。コネクタ穴は型番未確定のためまだ開けない。

ST3215のストール2.7A×3=8.1Aに対しUSB基板の上限は5A。5Aアダプターをつなぐだけで完成とはしない。給電分配・電流制限・ヒューズ・異常停止時の保持を設計する。予算内で保護を確定できない場合は電源構成を再選定する。
