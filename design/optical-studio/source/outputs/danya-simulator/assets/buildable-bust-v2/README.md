# Project DANYA：外装組立試作 v2

これは無通電の外装組立試作パッケージです。駆動ロボットとしての発注・本番印刷リリースではありません。現状は可動時に実寸プロジェクタが外装へ干渉します。

## 印刷
A1は256×256×256mm、AD5Mは220×220×220mm。共通基準はAD5M、0.4mmノズル、0.20mm積層、PETG、4周壁、20%インフィル、5mm外ブリム、必要箇所にサポート。温度・冷却・流量は使用フィラメントと実機で調整。G-codeは別機種へ流用しない。
- 最初は `M3-joint-coupon-hole-3.4.stl` を2個印刷。M3ボルトが手で通り、ナットと座金で割れずに締結できるか確認。きつければ3.6mm、緩すぎれば3.2mm試験片を比較。選択した穴径を本体へ反映してから本体印刷。
- `shell-*-print.stl` が各部品をベッド原点側へ移したデータ。1部品ずつ、底面をベッドへ合わせて印刷。合計8部品。`assembly-coordinates.stl` は全体配置用で、そのままベッドに置かない。
- メッシュ辺の閉鎖・一体性と造形範囲を確認済み。サポート除去、実物公差、締結工具アクセス、耐熱・強度は実物試験前。

## 組み立て順（外装のみ）
1. 上下各4部品を、内部の垂直接合部で仮組み。各リング4本、合計M3×20を8本使用。ナットとボルト頭の双方に座金を入れる。
2. 上下リングを水平接合部8か所で合わせ、残り8本で接続。内部へ工具を入れるため底面を開いたまま作業。順番によって工具が入らない場合は最後の後側部品を外して作業し、アクセス不良を設計へ反映。
3. 全部のねじを仮締めして外形を揃えてから手で軽く締める。樹脂接合部への指定締付トルクは未評価。
4. 底板・機構・頭部はこの外装へまだ取り付けない。外装のねじ接合部を駆動機構の支持に流用しない。

## 鏡
DXFとSVGはmm単位の予定有効光学領域。切断発注図ではなく、面取り・保持代・製作公差を含まない。主鏡3mm厚は既存頭部に接触、2mm厚も約0.328mmしか余裕がなく本番不適合。表面反射鏡の特注厚みと固定部を再設計し、光束欠けを再検証する。

## 駆動の計算条件
XM430の4.1Nmはストール値。公式米国ページの0.82Nmはストール値の20%に基づく推定であり、連続動作保証ではない。CSVは質量1〜2kg、重心20〜60mm、慣性0.03kgm²、角加速度0.5rad/s²、配線抵抗0.05Nm、安全係数2で比較。減速機効率80%は仮定。実重量・重心・加減速・通電温度が確定するまでモーター発注を保留。

## 残る設計
可動時収納、支持軸と減速機、主鏡の厚みと固定、小鏡角度調整、映像の合焦と光量、HDMI/DC端子の実寸と抜き差し、配線の可動ループ、放熱、底板、転倒安定性、頭部との接続、非常停止後の頭部保持。これらを未検証のまま「印刷すれば完成」と扱わない。
