# DANYA 首・内部機構の再設計案 v4

2026-09-22。承認されたv3外装と元の頭・顔を維持した機構配置案。完成した製作図・発注承認ではない。

## 構成と荷重の流れ

固定ベース → 中空の左右回転キャリア → うなずきヨーク → 傾きキャリア → 頭・鏡・プロジェクタの一体フレーム。

- 回転中心はX=-22.016、Y=0.346、Z=20mm。首の接続断面から22.606mm下に置く。外側の首を伸ばさず、首の真下に機構を収める。
- 左右回転キャリアはZ=-20、外径100／内径82／厚6mmのリング案。固定側の環状すべり受け・押さえで支持する。表示した支持トラックは配置用で、摺動材・摩擦・保持機構・歯形は未確定。
- うなずきヨークは外径100／内径92／厚6mm。左右の8mm軸と688ZZ相当（8×16×5）2個で支持する案。
- 傾きキャリアは外径82／内径74／厚6mm。前後の8mm軸と688ZZ相当2個で支持する案。
- 軸受を含むボス・シャフト締結は追加設計が必要。6mmのリングに単に8mm穴を開ける構造にはしない。現在のリングSTLは比較・配置用で、そのまま荷重部品として印刷しない。
- モーターは荷重支持用軸受と分ける。ST3215 12V版3台。左右軸モーターは固定ベース、うなずきモーターは左右回転キャリア、傾きモーターはうなずきヨークへ取り付ける。
- うなずき・傾きは40T/20Tの2:1減速、GT2相当2mmピッチ・幅6mmのベルト案。中心距離100mmで探索。260mmベルトなら中心距離は約99.8mmとなるため、張り調整スロットと調整位置での干渉再検査が必要。現時点で260mmを発注確定しない。
- 左右軸は150T/20T相当の7.5:1外周歯車を検討。今の軸間54.37mmは概略包絡値で、実際のピッチ軸間約54.11mmに合わせる調整が残る。歯形は未生成。

サーボ軸位置・向きはselected-drive-layout.jsonに記録。首付近へモーターを集めた案は光路・相互干渉で棄却し、胸側へ離した候補を採用した。

## 検査結果と限界

1. プロジェクタ全体の凸包309頂点を、1度刻み10,309姿勢で胴体の内側楕円断面と比較。最小断面指標4.768mm。3mmの半径方向壁代を仮定。これは3D最短距離や非凸容器への完全包含・連続動作の証明ではない。
2. 頭と顔の実メッシュ対v3外装表面は27組合せで交差0。柔軟カバーの変形・厚みは含まない。
3. 実寸ST3215の約1mm余裕付き外接箱を用いて、27姿勢でプロジェクタ・外装・他モーターとの配置を探索。光線の追加検査も通る候補から、相互干渉しない14,004組の候補から1組を選んだ。選定されたモーターの最小断面指標は9.95mm（selected-drive-layout.jsonに記録）。非凸外装への箱の完全包含の証明ではない。
4. うなずき・傾きの大プーリー包絡（直径28×厚6mm）対プロジェクタ表面は27姿勢で交差0。左右軸の環状歯車はこのプーリー検査に含まない。
5. 3枚の中空リングは27姿勢で頭・顔・外装表面との交差0。サンプリングした主光線の遮断も0。有限瞳の光束は未検証。
6. ベルトの直線4区間は厚2×幅6mmでモデル化。27姿勢でプロジェクタ凸包との表面交差0、光線対ベルト包絡+4mmの簡易余裕検査も遮断0。巻付き部、ベルト同士、他モーター、軸受、支持部との交差を保証するものではない。
7. サーボについても主光線対外接箱+4mmの検査を実施。実際の瞳径・投射レンズ・口径による光束を再現したものではない。

表示した支持柱・小型軸受・小径プーリーは27姿勢で頭・顔・外装表面との交差0。ただし機構同士・プロジェクタ・光束との全検査は未完了。固定トラック、全ての締結部、頭とプロジェクタへの荷重フレームも未検証。部品同士の全組合せを通過した完成機構とは扱わない。

## モーター・荷重

[ST3215公式仕様](https://www.waveshare.com/wiki/ST3215_Servo)は12V版30kg·cm、無負荷45rpm、拘束電流2.7A。30kg·cmは連続使用トルクとして採用しない。実物の重量・重心が未計測で、保持トルクと熱の合否は未確定。

例として1kgの可動体の重心が軸から水平方向に100mm離れれば重力トルクは約0.981N·m。2:1減速・効率75%の仮定でサーボに約0.654N·mが必要となるが、これを連続保持できるとは未確認。実測重心に応じたバランス調整、速度・加速度制限、端部ストッパーが必要。

## 配線・組立設計の方針

- HDMIとプロジェクタ電源は後方サービス部から引き込み、固定側で張力止めを設ける。左右回転は±30度に制限し、スリップリングは使わない。可動側のケーブルループ・コネクタ抜差し領域は次の詳細設計対象。
- [Bus Servo Adapter(A)の定格上限5A](https://docs.waveshare.com/Bus_Servo_Adapter_A/FAQ)に、3台同時拘束の8.1Aを流さない。サーボ給電は別分配、共通GNDと信号線を接続し、基板のV端子へ負荷電流を逆流させない構成を検討する。供給電源・配線定格・分岐保護は未確定。
- 機構を先にベースへ仮組みし、摩擦と無負荷動作を確認。その後一体光学フレームを取り付け、配線・負荷・干渉を確認してから外装を付ける。外装に直接モーター荷重を受けさせない。
- 部品予算上限30,000円は維持。現段階は配分枠で、鏡・伝達部・電源の見積確定前。発注なし。スライスなし。

小型軸受の寸法参照：[NSK 688AZZ1シリーズ](https://www.nsk.com/engineering/products/bearings/ball-bearings/deep-groove-ball-bearings/extra-small-ball-bearings-and-miniature-ball-bearings-metric-series/688azz1-esm-md.html)。開放型688と幅が異なる場合があるため、シールド付きの型番・幅5mmを確認して選定する。
