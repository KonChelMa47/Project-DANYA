# DANYA 胸像外観の作り直し — 2026-09-22

前案の長く曲がった首を廃止。首中心だけを移すのではなく、胴体全体を頭の下へ置く外観として作り直した。頭・顔のSTLは変更していない。

- 最大肩幅300mm。胴体高さ184mm。断面最大奥行232mm（位置ごとの中心移動があるため全体包絡奥行とは異なる）。
- 追加の首カバーはZ24～42.606、約18.6mm。前案の約62.6mmから短縮。
- 上部肩を持ち上げ、首から肩へつながる低い曲面とした。大胸筋状の局所的な隆起や見せるための水平分割線を廃止。
- マットなオフホワイトの一体的な外観。前面の濃色パネルはサービス／通気部分の意匠候補。開口・排熱・取付構造は未設計。
- 首上端は元の頭部断面の低周波成分で滑らかにしたカバー。元頭部のメッシュは変えず、カバーの接合・公差は未確定。

参考：[Furhat公式](https://www.furhatrobotics.com/furhat-robot)。製品のコピーやメーカーCADの流用ではなく、顔を主役にした簡潔な胸像という外観方向を参考にした独自の形状案。

## 内部確認

最初の奥行206mm案では実寸プロジェクタの先端が胸の前面から出たため、不採用。首や頭を変えるのではなく、胸の下側を滑らかに前へ膨らませた。修正版は中立時の309凸包頂点・3mm半径方向壁代の簡易検査で、楕円断面余裕の保守的指標が最小5.64mmとなった。

頂点検査は非凸な筐体への完全収納や連続動作を証明しない。首を動かした際の干渉、ベルト・軸受・モーター支持、ケーブルの曲げ、鏡支持、実光束、排熱は未検証。旧外装の各種合格値はこの案に適用しない。画面のスライダーは外観を動かすための暫定表示。

この外装データは開いた表面で、印刷できる完成ソリッドではない。部品予算3万円は維持し、スライスは引き続き保留。
