# DANYA 共通後頭部接続 改訂03

固定式投影試作とモーター式の両方に適用します。

## 変更

- 首元内側の細いトゲを切除。底縁を組立Z=50.65 mmに平坦化（約0.54 mmの局所トリム）。頭部の大きさや顔は変更していません。
- 大鏡取付台を後頭部へ一体化。旧接着層を埋め、ねじ頭・ワッシャーの逃げを追加しました。鏡の反射面・角度・切断輪郭は従来どおりです。
- 後頭部内側4か所に捕捉ナット受けを一体化。静止試作の長いアーム、本番機構の短い支柱を同じ接続位置へねじ固定します。
- 顔側・後頭部側の一体型磁石ホルダーはそのまま。磁石Ø5.9×2.9 mmを各4個、接着剤用の溝と着座部を備えたポケットへ二液エポキシで固定します。

## 追加金具と組立

各接続：M3×8六角穴付きねじ1本、対辺5.5×厚さ2.4 mmのM3ナット1個、外径7×厚さ0.5 mmのM3ワッシャー3枚。全体でねじ4本・ナット4個・ワッシャー12枚です。

1. 後頭部の六角穴（対辺5.8 mm）へ、内側からナットを入れます。
2. 左右の支持部の平らな面を合わせます。支持部がナットを覆い、脱落を防ぎます。
3. ねじ頭側へワッシャーを3枚重ね、M3×8で締結します。設計上のねじ先と盲穴底の間隔は0.2 mm。実物のねじ長さ・ワッシャー合計厚さを測り、面が密着する前に底付きしないことを確認してください。
4. 静止試作はアーム下端を既存のM4接続へ。本番機構は上部支柱を既存キャリアのM3接続へ取り付けます。左右を入れ替えないでください。
5. 大鏡固定板を一体型取付台へ、従来のM3×12とワッシャー2組で固定します。大鏡・小鏡の保持と3点調整方式は維持しています。

頭部保持と鏡取付台を後頭部へ接着する工程は不要になりました。鏡を裏板へ固定する接着と、磁石の接着は必要です。

## 検査の範囲

`shell-report.json`：後頭部が閉じた1つのメッシュであること。
`optical-check.json`：顔の167,698評価点へ向かう光路と、変更支持部・金具の比較。静止試作の新支持部は遮蔽なし。本番根元に既存の遮蔽は残っており、全顔照射の達成判定ではありません。
`head-optical-check.json`：後頭部と一体鏡架台による新たな遮蔽の比較。
`motion-check.json`：変更部を左右−30〜30°、頷き0〜12°、傾き−6〜6°、各3°刻みの525姿勢で検査。面接触やねじのかみ合いを含む生の検出結果です。
`mating-check.json`：後頭部との接合部の食い込み確認。支持面・鏡固定面は数値上の同一面を判別するため0.01 mm離した補助検査を併用しています。

全機構の連続角度での無干渉、実物の締結・保持強度、温度、投影品質の試験は未完了です。今回のファイルは形状を確認した試作設計です。
