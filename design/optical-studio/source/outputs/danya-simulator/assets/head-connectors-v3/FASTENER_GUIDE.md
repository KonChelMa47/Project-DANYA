# ねじ・金属ナットの入れ方

対象：固定式投影試作03と、本番機構の後頭部接続v3。樹脂へねじ山を直接印刷する方式には変更しません。

## 丸穴のままでよい理由

丸穴はねじを通す穴です。締め付けるためのねじ山は、市販の金属ナットにあります。六角形のくぼみはナットを入れ、回り止めにする場所です。六角穴がない貫通接続では、反対側にワッシャーとナットを当て、工具でナットを押さえます。すべての丸穴へナットを押し込むわけではありません。

組立表示のねじ・ナットも、形状を軽くするためねじ山を省略したものがあります。それらのSTLを印刷して使わず、市販品を使ってください。印刷対象は試作セットの `print/` にある部品です。

## 後頭部と左右支柱：最初に確認する接続

1. 後頭部の内側、首元左右に2個ずつある六角形のくぼみを見つけます。磁石用の丸いポケットとは別です。
2. 各くぼみにM3六角ナット（対辺5.5 mm・厚さ2.4 mm想定）を1個入れます。ナット穴とその奥の丸穴を合わせます。ナットは合計4個です。
3. 支柱の平らな取付面を当て、ナットを覆います。取り付けた支柱がナットの抜け止めになります。
4. 支柱側から **M3×8ねじ＋厚さ0.5 mmのワッシャー3枚** を通し、ナットへ締め込みます。左右各2本です。
5. 実物のワッシャー合計厚さ1.5 mmを確認します。盲穴なので、長いねじへ変更しないでください。ねじが底に当たっているだけで部品が締まっていない状態を避けます。

順番：ねじ頭 → ワッシャー3枚 → 支柱の丸穴 → 後頭部に入れた金属ナット → ねじ先の逃げ穴。

## 固定式試作：すべての接続グループ

|接続箇所|使用するねじ|ナットを置く場所・順序|
|---|---|---|
|台座左右の連結、台座の脚|M4×25|貫通穴の反対側へM4ワッシャー・ナット。先にボルト頭側にもワッシャーを入れる。脚の頭側は下面のくぼみに収め、ゴム底は締結後に付ける。|
|頭部支柱と台座、支柱と上部アーム|M4×25|部品の穴を合わせて貫通させ、反対側へワッシャー・M4ナット。ナットを工具で保持して締める。|
|プロジェクタ架台4本と台座、小鏡架台と台座|M4×25|貫通穴の反対側へワッシャー・M4ナット。|
|プロジェクタ架台と受け|M3×10|受け `drop-projector-tray-t5` の裏面4か所へ先にM3ナットを入れ、架台側から締結。|
|プロジェクタ押さえクリップ4個|M3×20|押さえクリップ・パッド・受けを合わせ、対応する反対側のM3ナットで締結。パッドや基板を潰すほど締めない。|
|後頭部と上部アーム|M3×8|上記の4か所。後頭部側へナットを先に入れ、支柱で覆う。ワッシャーは各3枚。|
|大鏡固定板と後頭部の一体型取付台|M3×12、2本|大鏡固定板へ前側からM3ナット2個を先に入れる。裏板を重ねる前に作業し、取付台の後ろ側からねじとワッシャーで固定。|
|小鏡固定板と架台|M3×12、2本|小鏡固定板のM3ナット2個を先に入れ、架台側からねじとワッシャーで固定。|
|大小の鏡の3点調整|M3×12、各3本|各鏡の裏板へ後ろ側からM3ナット3個を先に入れる。固定板・弾性スリーブ・裏板を組む。ナット挿入後に鏡を接着する。|

試作の必要数：**M4ナット26個、M3ナット22個**（予備除く）。M4ワッシャー52枚、M3ワッシャー30枚。ねじ長さの内訳と部品別手順は [試作の組立手順](../projection-prototype/ASSEMBLY.md) を参照してください。M4の通常ナットは対辺7 mm・厚さ3.2 mm、M3は対辺5.5 mm・厚さ2.4 mmをモデルで想定しています。

## 本番機構に残っている例外・未確定部分

**本番機構のすべての接続が、すでにナット式になっているわけではありません。** 現在の部品表には次の設計が残っています。

- `yaw-upper-leg-*`：アルミ加工品にM2・M3のタップを立てる前提。丸い下穴のまま印刷した樹脂へ、そのまま締め込む設計ではありません。
- `pitch-bearing-cap-*`、`roll-bearing-cap-*`：相手側の金属タップへM2ねじで固定する前提。
- `lift-carrier-countersunk-bolt-*`：脚側のねじ受けを前提とした接続。全体を「印刷部品＋市販ナット」に統一するには、この受けを再設計する必要があります。
- `*-backmount-*-screw-*`：モーター本体の既存穴へ取り付けるねじ。モデルにはM2×10候補がありますが、実機のねじ規格・深さは未確定です。ここへナットを入れる構造ではありません。

これらを「ナットを入れれば組み立てられる」とは扱いません。今回は方式の確認と組立説明の追加であり、未確定部分の形状変更・実物組立試験は行っていません。

## 入らない場合

ナットは六角ポケットに向きを合わせて入れます。サポート材が残っていないか確認し、工具やねじで無理に引き込まないでください。ナットが入らない、空回りする、ねじが斜めになる場合は、その部品名と箇所を基に寸法を調整します。スライサーで全体を拡大・縮小すると、他の接合寸法も変わります。

[現行マニフェストのねじ関連部品一覧CSV](FASTENER_INVENTORY.csv) は、部品名・材質・元の設計注記を収録しています。自動抽出した参照一覧で、購入数の確定表ではありません。
