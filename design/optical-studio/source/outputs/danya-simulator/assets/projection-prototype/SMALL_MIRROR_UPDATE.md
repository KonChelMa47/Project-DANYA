# 小鏡の改訂 — 49×100mmの角落とし形状

2026-09-24 / small-mirror-v1。変更したのは小鏡の外形と切り出し型です。小鏡の脚・裏板・固定板・調整ねじ、プロジェクタ、トレー、P1〜P4、大鏡、頭部は変更していません。旧小鏡23.828×35.185mmの寸法指示より、この文書を優先してください。

## 切り出しと取り付け

- ガラス厚1.5mm。49×100mmの長方形から一角を斜めに切り落とす五角形です。曲線切断は不要です。
- 型紙は `foldMirror-cutting-outline.svg`。印刷100%、20mmの確認線を測ってから使います。
- 3Dプリント用の型は `print/foldMirror-cutting-master.stl`。49×100×2mm、底面Z=0。小穴2個は位置を写すペン穴であり、ガラスに穴を開ける指示ではありません。
- 反射面側から見た切り出し座標（左下を0,0、mm）：(0,0) → (49,0) → (49,32) → (9.7,100) → (0,100)。49×100mmの長方形を用意し、右辺の下から32mmと上辺の左から9.7mmを結んで余分な角を落とします。
- **既存の裏板の中心は、鏡の外接長方形の中心ではありません。** 左端から32.5mm、下端から20mmの型紙の十字へ合わせます。もう一つのペン穴は同じX、下から30mmで、既存鏡の局所上方向を示します。
- 裏側へ型を写す場合は左右反転して使います。取り付けの上下・表裏を確認してから接着してください。
- 元の3点接着位置・設計接着層1mmを維持します。今回の改訂は鏡を面内で非対称に広げるもので、反射面の位置や角度、脚の取り付け位置を動かすものではありません。

機構の印刷部品を刷り直す必要はなく、切り出し型だけが新しい印刷データです。大きなガラスの片持ち部分と接着強度は実物未試験です。

## この寸法の検査条件

実機のレンズ開口は未測定です。仮定した出口瞳径8mm、前後位置−5/0/+5mm、合焦面200/350/450mm、全画面四隅と瞳周256点＋中心を評価しました。表面鏡と、厚さ1.5mm・屈折率1.52の理想的な裏面鏡の両方で、検査した境界光線の欠けは0件です。実機での保証値ではありません。

三角形による接触検査では接触するのは既存の接着パッド3個のみ。その他部品との表面交差は検出されませんでした。公差を含む必要クリアランスや実物強度を保証するものではありません。

表面鏡モデルでは従来の全255,542点の顔への光路を保持し、光路頂点の変化は約1.8e-13mm（数値誤差）です。追加した鏡が元の光路を途中で遮る件数も0件でした。ただし、磁石アーム等の既存の影を解消したという意味ではありません。

裏面鏡ではガラスの表と裏の反射による副像・位置ずれが残ります。ダイソーの鏡の材質・コーティング・実際の屈折率を測定したモデルではありません。大型化で二重像は解消しません。

## 画面の傾きについて
