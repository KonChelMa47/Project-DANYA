# DANYA 頭部・顔・磁石支持枠 v5

更新対象は **face / magnet-carrier / head-upper / head-lower の4部品** です。旧版と混ぜず、このセットで組み合わせてください。

## 改修内容
- 顔より張り出していた支持枠の段差を、支持枠と顔の外周を一緒に設計し直すことで修正しました。
- 顔は周囲の縁から10 mm以内の外側だけをなだらかに調整しています。目・鼻・口と、内側の投影面は元の形状を維持します。
- 顔と支持枠の接着面は、実際の顔メッシュに0.12 mmの逃げを取って合わせました。下側の磁石座と補強リブも作り直し、前方着脱と光路を確認しています。
- 後頭部の外面を連続した曲面として再構成し、古い外面の重なりを除去しました。
- 後頭部の主要壁は約4.3 mm。合わせ目の最後の約6 mmは支持枠につながる厚みへ移行します。穴・接続座・縁は一律4.3 mmではありません。
- 後頭部の分割は中央（組立座標Z=165 mm）。M4ねじ4本と位置決めピン2本を再利用します。
- 鏡・支柱・プロジェクタ・土台の位置は変更していません。

## 組み立て
1. 顔と支持枠を接着前に合わせます。支持枠の広い方の縁を顔の周囲へ合わせ、内側から接着して1つの着脱ユニットにします。顔の投影領域に接着剤を広げないでください。
2. 上側は直径3×厚さ1 mm、下側は直径5.9×厚さ2.9 mmの磁石を、顔側／後頭部側それぞれの座へ接着します。穴は接着剤の余裕を設けた設計で、圧入だけで固定するものではありません。必ず相手側と引き合う向きを確認してから接着してください。
3. 後頭部下側の接続座4か所へ、内側からM4六角ナットを入れます。
4. 位置決めピン2本を中央の穴に入れ、上下を合わせます。M4×20 mmねじ4本とワッシャー4枚を上から入れ、均等に締めます。
5. 従来の鏡・支柱の固定部を取り付けます。顔＋支持枠のユニットを前方から磁石で取り付け、外すときも前方へ引き抜きます。

## データ
- MODELS：4部品のSTLと同名3MF。
- 単位mm、倍率100%。STLは組立座標です。3MFは個別部品をベッドへ置く姿勢を持ちますが、スライス済みではありません。
- 4部品を同じプレートへ同時配置するデータではありません。
- VALIDATION：計算によるチェック結果。GUIDE：実STLの確認画像。

## 検証の範囲
閉じたメッシュ・連結・自己交差、壁厚サンプル、ねじ／ナット／ピン、磁石座、前方への着脱、固定光路のサンプルを検査しています。具体的な数値と許容差はVALIDATIONを参照してください。有限個の検査であり、全域の最小肉厚や実物の強度を保証するものではありません。

今回はスライス・実物の再印刷・強度・遮光試験は実施していません。灰色PLAの遮光性は銘柄や印刷条件にも依存します。
