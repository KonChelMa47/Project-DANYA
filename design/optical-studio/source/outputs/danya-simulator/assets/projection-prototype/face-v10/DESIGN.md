# 磁石支持枠 v10 — 静的試作改訂

現行モデルに採用済み。実物での投影・接着強度試験は未実施。

- 元の顔スクリーン（v8で0.5mm増厚した面）はそのまま使用し、旧左右の磁石アームを取り除く。
- 顔の周縁に沿う独立した磁石支持枠に変更。磁石は上2か所・下2か所。
- 支持枠を中心Y=0、Z=160mmに対してY/Z方向に0.3%広げ、光束から退避。
- 後頭部の磁石受けも対応する位置に移し、支持枠とのクリアランスを加工。
- プロジェクタ、トレー、P1～P4、大小鏡、土台、支柱とその取り付け部品の配置を保持。

顔と支持枠は別々に印刷して周縁で接着する案。接着用の隙間を設け、後頭部との公称配置での干渉がないことを確認。組立の連続した取り外し経路と接着強度は実物試験が必要。元の顔スクリーンを全体再メッシュして外観を変えることはしない。

支持枠単体の確認：1連結成分、非多様体エッジ0、0.01mmを超える非隣接三角形交差0、0.00001mm²を超える共面重なり0。拡大前の支持枠をアフィン変換しており、この位相・交差検査結果を維持する。

0.3%拡大した支持枠：255,542点に対する766,626本のキャッシュ光路で遮蔽0。点光源・公称配置の離散サンプル検証であり、実機の有限開口、製造公差、接着剤のはみ出し、透過・散乱、ピント・強度の保証ではない。
