# v10 顔・磁石支持枠の組み立て

この改訂は固定式の投影試作機用。下の土台、P1～P4、プロジェクタトレー、支柱、大小鏡は既存品を使う。顔の古い左右アームを残したv8顔と、新しい支持枠は併用しない。

## 交換する印刷部品

- face.stl：元の顔スクリーンを保持し、旧磁石アームを除いたもの。
- magnet-carrier.stl：顔の周縁に沿う独立した磁石支持枠。
- head-upper.stl / head-lower.stl：新しい磁石位置に対応する後頭部上下。

## 組み立て順序

1. 先に磁石を接着せず、支持枠・顔・後頭部を仮合わせする。支持枠の磁石位置は上2か所・下2か所。造形誤差があるため、磁石を無理に圧入しない。
2. 直径5.9mm、厚さ2.9mmの磁石を8個使用。向かい合う4組が吸着するよう、極性を確認して印を付ける。
3. 磁石を接着固定する。保持部は接着を前提とした開いた受け形状を含む。圧入や爪だけで保持する設計ではない。接着剤を光路や相手側の合わせ面へはみ出させない。
4. 顔と支持枠を正しい組立位置に仮固定し、周縁を接着する。顔の上下・中心と支持枠の上下・中心を合わせ、外側からテープなどで位置を保持する。後頭部を位置確認に使う場合、後頭部まで接着しないよう合わせ面を保護する。
5. 顔と支持枠の間には接着用の隙間がある。形状サンプル上の最短隙間は約0.20mmで、場所により広くなる。材料に適合する隙間充填用接着剤で接合し、スクリーン内面と光束側へ流さない。これは接着強度の実測値ではない。
6. 接着剤の指定条件で完全硬化させてから、顔＋支持枠を一つのユニットとして後頭部へ取り付ける。分解時も顔だけを引っ張らず、支持枠を持つ。鏡の取り付けは後頭部上側を外して行う。
7. 白画像と格子画像で周縁を確認する。接着剤のはみ出し、造形変形、鏡の角度はシミュレーションに含まれないため、実物で確認する。

## 検証の範囲

元の顔スクリーンの外形と厚さを保持。計算は公称配置・点光源の離散サンプル。強度試験、接着剤の透過・散乱、磁石の引抜き試験、組立の連続した取り外し経路は実物での検証が必要。
