# v12：露出機構を抑えた顔の取り付け

[Furhatの交換式マスク](https://www.furhatrobotics.com/furhat-accessories)の自然な外観を参考に、顔の輪郭に沿う縁と内蔵磁石に変更しました。Furhatの内部機構のコピーではなく、DANYAの既存スクリーンと光路に合わせた設計です。

外側のつまみを廃止し、上側は直径3×厚さ1 mmの磁石4個に小型化。下側は直径5.9×厚さ2.9 mmの磁石4個を維持しました。支持枠の周縁を後頭部の受け段に納めます。継ぎ目は残りますが、大きな磁石ホルダーは顔の外へ出しません。

顔の形状・厚さ、土台・トレー・脚・支柱、大小鏡、光学配置は変更していません。後頭部側は縁の受け段と内部の着脱逃げを変更しています。

検証結果は `validation-summary.json` を参照してください。光路は255,542本の公称幾何光線と変更部品の交差検査です。実機の明るさ・焦点・材料の透過率・二重像を保証しません。着脱は前方100 mmを離散位置で検査し、任意の傾け方や連続的な衝突の証明ではありません。

実物の保持力・接着強度・疲労・造形誤差、首開口からの指の届き方は未検証です。
