# v9 磁石アーム再配置 — 検証中・印刷不可

**現在の正式な印刷セットとビューアはv8のままです。このフォルダの試行STLは印刷しないでください。**

磁石4組を頬の左右から頭頂側2組・顎側2組へ移し、腕を内壁に沿わせる案を作成しました。磁石は引き続きØ5.9×2.9mm、接着用ポケットはØ6.15mm、内部の接着剤用溝はØ6.75mmです。

![現在の接合候補](fused-preview.png)

## 確認済みと未完了

- 新しい腕・受け・磁石の16形状だけを調べた検査では、255,542点×3区間の光路で遮光0件（candidate-all-check.json）。
- 顔と補強縁を一体化した候補`face-fused.stl`は1連結・閉じたメッシュですが、自己交差が残っています。印刷用として不合格です。
- 全体の厳しい光路検査では、885点で元の顔内面より先に新しい縁へ当たり、18点は到達判定未解決。面積概算の遮光率は約0.07248%、旧v8は約2.82357%。**全顔無影は未達成です。**
- 元の顔表面・公称0.5mm増厚後の投影面を維持する方針です。接合の数値安定化用に0.01mmの局所重なりを試しています。
- 顔と後頭部の着脱経路には干渉が残ります。通常の前方引き抜きは確認できていません。組立可能とはまだ扱いません。
- ユーザー承認後、既存のProject-DANYA仮想環境にpymeshfix 0.17.2をインストール済み。修復候補`face-fixed.stl`は交差長0.01mm超の自己交差が0件になりましたが、微小な同一平面の重なり5件が残っています。光路の面積概算遮光率も約0.38906%へ悪化したため、不採用です。最新の`optical-check.json`はこの修復候補の結果であり、上記`face-fused`の数値とは別です。

光路検査は点光源・理想反射・静止状態の幾何モデルです。実機の開口径、散乱、透過率、焦点、製造公差、接着強度、実物の投影は未検証です。境界頂点の数値誤差については、一部を元の隣接三角形の重心側へ最大約0.000102mmだけ移した再検査も行い、その数をレポートに記録しています。

候補は作業途中で更新されます。正式セットへの採用とSTLの差し替えは、光路・形状・接合・着脱の検査が通ってから行います。
