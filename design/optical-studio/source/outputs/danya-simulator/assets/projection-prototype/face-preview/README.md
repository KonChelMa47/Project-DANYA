# 試作機の顔投影プレビュー

現行の assembly/face.stl、layout.json、および組立部品243個を使い、プロジェクタ→小鏡→大鏡→顔の投影UVと遮蔽を計算。
顔の最後の連続した層は透過スクリーンとして扱う。表示は点光源の頂点サンプリングによる近似であり、面積照射率、実機強度、透過率、明るさ、焦点、二重像の検証ではない。

「顔全体に合わせる映像変換」はプレビュー内で元画像を投影UVへ変換。「入力映像をそのまま投影」は変換しない。実機のHDMI出力を変更しない。

build.mjsで生成したデータは頂点数と配置一致を読み込み時に確認。形状が更新された場合は再生成が必要。
ブラウザーで顔表示・全体表示・天井投影との相互切替を確認。STL形状は変更していない。
