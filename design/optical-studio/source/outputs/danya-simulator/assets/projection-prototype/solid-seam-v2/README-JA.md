# DANYA 後頭部の下端・接続修正版 v2

差し替え対象は **head-upper.stl / head-lower.stl の2部品** です。顔の支持枠は前回の合わせ目補強版を継続します。全体セットには対応する支持枠も含めています。

## 修正した内容

- 後頭部の首元に残った浮いた帯を除去しました。実際の後頭部に壁がある範囲だけを補強する形に作り直しています。
- 下端の薄い突出部を除去。後ろ側の底縁は水平、前側は首の開口へ向かう斜めの切り口で閉じています。下側磁石受けの下に十分な材料を残し、左右の尖った余りをなくしました。
- 首元後ろ側の荒れを局所的に均し、ねじ座・接合部・磁石の中心位置を保持しました。
- 下側の磁石受けを、外径8.8 mm・穴径6.4 mmの周囲が閉じた受けに修正。持っている直径5.9×厚さ2.9 mmの磁石を接着して使用します。受けの根元を幅のある形で後頭部へ接続しました。
- 上側の縁も同じ方法で補強を作り直しました。上側磁石の寸法・位置は変更していません。
- 顔、支持枠、土台、プロジェクタトレー、脚、鏡とその固定部は前回セットと同じです。

## 組立

上下の接続は既存のM4ねじ4本と位置決めピン2本を使用します。顔は支持枠と一体で前方へ取り外します。下側磁石の極性を顔側と合わせ、ポケットに接着剤で固定してください。保持力・接着強度の実物試験は未実施です。

全36印刷部品のメッシュ連結・境界辺と、組立位置における相手部品との近接関係を確認しました。修正した後頭部は追加で自己交差・開口の閉じ方・下端の外観・磁石穴・固定姿勢の光線・前方着脱を確認しています。
