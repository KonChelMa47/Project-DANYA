# 顔・後頭部の一体型磁石ホルダー（顔v8・後頭部v6）

`print/face.stl` に顔側の4個のホルダーを、`print/head-upper.stl` と `print/head-lower.stl` に後頭部側の4個を一体化しました。顔と後頭部は別々の印刷モデルのままです。旧版の `magnet-clear-*-face-return.stl` と `magnet-clear-*-head-cup.stl` は印刷しません。ホルダーを外装に接着する工程は不要になりました。

![補強後の顔の内側](face-v8/reinforced-face.png)

顔は公称0.5 mm増厚、戻り腕は0.8 mmウェブ＋最大2 mmの上下リブで補強しました。**縁の遮光は増えています。** 最新の[光路検査・影の位置図](face-v8/README.md)を確認してください。

## 磁石の固定方法

使用する磁石は **直径5.9 mm、厚さ2.9 mm、計8個（4組）** です。

|部分|設計値・役割|
|---|---|
|挿入口の直径|6.15 mm。磁石に対し直径方向0.25 mmの余裕。無理な圧入はしません|
|ポケット内部の環状溝|直径6.75 mm・軸方向幅1.0 mm。硬化した接着剤が掛かる形状|
|底の着座ストッパー|3か所。磁石の深さを決め、ストッパー以外の底面に接着剤の層を確保|
|磁石表面の引込み|各0.15 mm。磁石の厚さ2.9 mmで着座した場合|
|ホルダー同士の間隔|0.20 mm|
|磁石同士の間隔|0.50 mm。外装の接合面の隙間とは別です|
|外装の接合面|従来位置を維持。設計上の隙間0 mm|

磁石は、**印刷材料と磁石のめっきの両方に適合する二液エポキシ**で固定します。環状溝は硬化後の接着剤の軸方向の抜けに抵抗するための形状です。磁石自体は接着で保持するため、接着なしで抜け止めが成立する構造ではありません。機械式のふたやスナップ爪は設けていません。

顔側ポケットは奥行き3.20 mm、底のストッパー高さ0.15 mm、後頭部側は奥行き3.30 mm、ストッパー高さ0.25 mm。どちらも磁石が入る有効深さ3.05 mmです。磁石をストッパーへ着座させると、表面が0.15 mm奥に収まります。

## 先に確認用パーツを印刷

`print/magnet-fit-coupon.stl` は56×16×5.5 mmです。くぼみの数と穴径の対応は次の通りです。

|目印|穴径|
|---|---|
|くぼみ1個|6.00 mm|
|くぼみ2個|6.15 mm：頭部・顔に採用した径|
|くぼみ3個|6.30 mm|
|くぼみ4個|6.45 mm|

本体と同じ材料・ノズル・印刷設定で作り、まず接着剤なしで試します。2個のくぼみの穴に磁石が手で入って着座することを確認してください。入らない場合は、本体全体を拡大せず、穴補正またはポケット径の修正が必要です。実物の寸法・印刷収縮は未検証です。

## 印刷と組立の順番

1. 確認用パーツで穴の合い具合を確認します。
2. 後頭部上下2分割と `face.stl` を印刷します。外形を維持し、各部品はA1・AD5Mの造形範囲内です。顔側の内向きの張り出しにはサポートが必要です。磁石の穴・環状溝・3点ストッパーをサポートで埋めないよう、スライスを確認します。
3. 穴のバリとサポートを除去し、磁石がストッパーに当たることを確認します。補強済みの戻り腕にも無理な曲げを加えないでください。
4. 磁石を4組に分け、向かい合う面が吸着する極性で印を付けます。ブラウザの分解表示かBlenderモデルで、各組の位置を確認できます。
5. 顔と後頭部を離した状態で、ポケットの側面・溝・ストッパー以外の底面へ少量の接着剤を入れます。ストッパーの先端に厚い接着剤の塊を残さないでください。
6. 磁石を入れて3点ストッパーへ着座させます。磁石表面とホルダー前端へはみ出した接着剤を取り除きます。磁石の面が0.15 mm奥にあることを確認します。
7. **顔と後頭部を閉じたまま硬化させず**、離した状態で各側を保持して、接着剤メーカー指定の時間まで硬化させます。
8. 硬化後に各磁石を個別に確認してから顔を合わせます。顔を何度か着脱し、磁石や戻り板が動かないことを確認します。十分な保持力があるかは実物で判断する必要があります。

## 検証と限界

- 顔、後頭部ともホルダーを含めて1つにつながった閉じたメッシュとして検査しています。
- 追加部分が元の頭部・顔の外側へ出ないことと、相手側のシェル・ホルダーへの表面干渉がないことを確認しています。
- 接着強度、磁石の実際の吸着力、反復着脱耐久性は未試験です。公差や保持力を実物で確認するための試作です。
- 最新の幾何光路検査は [face-v8/README.md](face-v8/README.md) と `face-v8/optical-check.json`。縁の遮光面積概算は約0.36%から約2.82%へ増加。顔の厚み追加でも少数の複数面交差があり、全顔100%照射の達成とは扱いません。
