# v11：顔ユニットを工具なしで着脱する構造

顔スクリーンと磁石支持枠は接着して一つのユニットにします。このユニットを後頭部から磁石で着脱します。顔スクリーン単体を日常的に剥がす方式ではありません。

## 変更する部品

- **magnet-carrier.stl**：あご下に2つのつまみを追加。鏡の後ろへ回り込む上側アームを短縮し、上側の磁石を前方へ移動。
- **head-upper.stl**：上側の磁石受けを対応する位置へ変更。
- **head-lower.stl**：顔を引き出す際に引っ掛かる下端の内側を逃がす。

顔が旧支持枠に接着済みで剥がせない場合は、顔スクリーンも同じデータで再印刷してください。新旧の支持枠を無理に剥がして交換しないでください。

顔スクリーン、大小鏡、支柱、土台、トレーはそのまま使います。上側の旧磁石位置は使いません。v10の支持枠とv11の後頭部は組み合わせないでください。

## 組立

1. 3部品を仮合わせし、顔ユニットが前へ抜けることを確認します。造形誤差があるため、力で押し込まないでください。
2. Ø5.9×2.9mmの磁石を4組・計8個使います。下側は従来位置、上側は新しい受けへ移します。上側の既存磁石を無理に剥がすより、新しい磁石を用意しても構いません。
3. 向かい合う磁石の極性を確認します。受けは開いた接着保持形状を含み、圧入用ではありません。樹脂と磁石に適合する接着剤で固定し、相手側や光路へはみ出させないでください。上側磁石中心の高さは組立座標で255.5mmです。
4. 顔スクリーンを支持枠の周縁へ接着します。位置を合わせ、後頭部と接着してしまわないよう合わせ面を保護します。元の顔の厚さと外形は変更していません。
5. 完全硬化後、机上で顔ユニットを両手で支えて仮着脱します。磁力や接着強度は実物で未測定です。

## 普段の取り外し

1. 映像を止めます。
2. あご下の左右のつまみを持ち、上側の支持枠にも手を添えて落下を防ぎます。薄い顔面や鼻をつかまないでください。
3. 顔＋支持枠を、ねじらずにまっすぐ前へ引きます。最初の数mmはゆっくり磁石を離し、そのまま引き出します。
4. 取り付けは逆順です。磁石で勢いよく吸着させず、支持枠を持って最後までゆっくり戻します。

## 検証の範囲

組立座標の+X方向へ100mm引き出す経路を、最初の15mmは0.25mm刻み、その先は1mm刻みで検査します。これは離散サンプルの幾何検査で、連続運動や任意方向へねじる動作の保証ではありません。磁力、接着強度、造形公差、落下・疲労試験は未実施です。詳細は同梱のvalidation-summary.jsonを参照してください。

印刷用STLはmm単位、倍率100%。支持枠は造形台上で30°回転した姿勢です。外接寸法は約175.3×215.1×51.9mm。3部品ともA1・AD5Mの造形枠内です。実際のスライスと造形条件の確認は別途必要です。
