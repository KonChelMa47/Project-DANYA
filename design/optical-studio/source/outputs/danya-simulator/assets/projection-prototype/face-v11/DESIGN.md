# v11 着脱構造の見直し

v10では前方へ引き出す途中に上側アーム・磁石が大鏡と後頭部に接触していました。

v11は上側の磁石を大鏡の前側へ移し、長い戻りアームを短縮しました。あご下に剛性のあるつまみを2か所設け、後頭部の下端に抜き出し用の逃げを設けました。顔スクリーンの形状・厚さ、大小鏡、支柱、土台、トレー、光学配置は変更していません。

前方100mmの経路を離散位置で検査し、顔＋支持枠＋顔側磁石と固定部品の接触は0でした。初期15mmは0.25mm間隔、その先は1mm間隔です。任意の傾け方や連続衝突の証明ではありません。

変更した7つの組立メッシュを25万5,542本の公称光路（各3区間）と照合し、変更部品による遮蔽は0でした。印刷する3部品はいずれも1連結・非多様体エッジ0で、規定の閾値を超える面の交差・重複は検出されませんでした。

実物の磁力・接着強度・疲労・造形誤差は未検証です。磁石の吸着力を保証するものではありません。
