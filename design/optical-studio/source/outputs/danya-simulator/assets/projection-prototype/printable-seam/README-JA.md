# 顔・後頭部の合わせ目：印刷用の縁を補強した版

差し替える部品は **magnet-carrier（顔の磁石支持枠）、head-upper（後頭部上）、head-lower（後頭部下）** の3個です。3個をセットで交換してください。顔スクリーン自体は従来品を使用します。

## 変更

- 支持枠の合わせ目は従来の約0.25〜0.85 mmの薄い縁を、法線方向1.4 mmを目標に外側へ補強。局所的な傾きと丸めを考慮して形状を調整しました。部品の全箇所に一律1.4 mmの最小厚さを保証する意味ではありません。
- 後頭部の薄い重なりを整理し、縁の外側を補強して約8 mmの範囲で元の面につなげました。顎側の消えやすい縁には丸みを付けています。
- 合わせ目は前後方向に設計クリアランス0.30 mm。薄い唇状の重なりで隙間を隠す方式をやめ、着脱に必要な逃げを設けています。完全なゼロ隙間ではありません。
- 後頭部は上3/4・下1/4の分割を維持。分割用ねじと位置決めピンは従来どおりです。
- 顔は支持枠と接着して一緒に前へ外します。磁石は上側Ø3×1 mm、下側Ø5.9×2.9 mmを継続します。

## 印刷

単位mm、倍率100%。付属の **3MFは各部品1個ずつの印刷方向とベッド配置を持つモデルファイル** です。AD5M用の0.4 mmノズル・0.20 mm積層・4周壁・PLA・自動サポートありの設定でスライスを確認しました。3MFに材料やプリンターの設定は埋め込んでいません。お使いの設定を適用してください。

STLは形状の精度を保つため組立座標で収録しています。STLから印刷する場合はスライサーで「ベッドに配置」と印刷方向の指定が必要です。上部は分割面を下に、下部は上下反転して分割面を下にします。支持枠は3MFの配置を推奨します。3部品を同じプレートに同時配置するデータではありません。G-codeは含めていません。

この説明を合わせ目についての最新版として使用してください。後頭部の上下接続方法は従来のHEAD_NEW_SPLIT.md、磁石の接着・極性確認はFACE_V12.mdを参照してください。古いPDFの薄い縁と中央分割の形は採用しません。

## 検証範囲

VALIDATION内に最終STLのメッシュ確認、実際のスライス経路との照合、既存の固定姿勢光線との交差検査、前方着脱の離散姿勢検査を収録しています。有限個の光線と角度・位置サンプルによる検証です。実機印刷、実物の磁石の保持力・強度・投影画像は未確認です。
