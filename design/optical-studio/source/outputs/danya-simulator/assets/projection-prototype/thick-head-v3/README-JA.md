# DANYA 後頭部・厚肉／中央分割版 v3

再印刷するのは **head-upper / head-lower の2部品だけ** です。灰色PLA・0.4 mmノズルで前回の薄い壁が剥がれた問題に対応しました。

## 変更
- 約1 mmだった後頭部の主要な壁を、**約4.2 mmを目標**に外側へ厚くしました。顔の接合縁、磁石受け、ねじ穴などは用途に合わせた局所形状です。全ての箇所が一律4.2 mmという意味ではありません。
- 首元の薄い範囲も追加補強しました。内側の光路・取り付け位置を維持するため、主に外寸が約3.2 mmずつ増えます。
- 分割を**ほぼ中央（組立座標Z=165 mm）**へ変更。上側約113 mm、下側約114 mmの高さです。
- 旧1/4位置の上下接続部を撤去し、中央に4か所のM4接続部と2か所の位置決めピン穴を設けました。
- 顔、顔の支持枠、磁石の中心、鏡・鏡の固定具、支柱、土台、プロジェクタのトレーは変更していません。

## 組み立て
1. 旧上下の後頭部を外し、鏡・固定金具・磁石を新しい後頭部へ移します。接着済み磁石が外せない場合は同寸法の磁石が別途必要です。
2. 下側の接続座4か所へ、内側からM4六角ナットを入れます。
3. 既存の位置決めピン2本（約直径3.95×長さ6 mm）を中央の穴に入れて上下を合わせます。
4. M4×20 mmねじ4本・対応ワッシャー4枚で、上側から下側のナットへ締結します。4か所を少しずつ均等に締めてください。樹脂のねじ山ではなく金属ナットで締結する構造です。
5. 既存の顔＋支持枠を前方から磁石で取り付けます。鏡や支柱の固定位置は従来どおりです。

## 確認と限界
メッシュの閉じ方・連結、壁厚サンプル、ねじ／ナット／ピン、顔の前方着脱、固定姿勢の光線サンプルを計算で確認しています。詳細はVALIDATION内にあります。壁厚測定は有限個の法線方向サンプルで、全域の最小厚み保証ではありません。自己交差検査には数値許容差があります。

今回はスライサーによる確認・実物の再印刷・強度試験は行っていません。3MFも材料やサポートの設定を確定したものではありません。厚肉化で改善を狙っていますが、灰色PLAの遮光性は銘柄や印刷条件で変わり、完全遮光の実証はできていません。まだ光が透ける場合は後頭部の内側だけに不透明な塗装などの遮光処理を行ってください（顔スクリーンには塗りません）。
