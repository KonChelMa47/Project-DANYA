# 頭内収納案 — 光学エンジン概形による検証

## 現在の状態

元の顔・後頭部の外形を保ち、光学エンジン概形と鏡2枚を頭内に配置しました。現在のシミュレーターはこの案です。**評価基板・ファンを含む実機一式の収納は未検証**であり、製造確定版ではありません。

TI公式の評価キットSTEPデータを取得し、承認を受けて `cadquery-ocp` を導入しました。実形状を使った収納検証を進めています。この文書は概形による先行案の検証結果です。

## 寸法と配置

シェルと検証対象部品の外接寸法：**高さ204.2107 ×幅144.6044 ×奥行181.8306 mm**。光学エンジン概形・2枚の鏡は外形からはみ出しません。前案の首下への突出をなくしました。

- 光学エンジン概形：56.97 ×21 ×80.35 mm。レンズ基準との関係は仮定を含みます。
- 折り返し平面鏡：16.936 ×24.980 mm、厚さ1.5 mm。
- 凸球面鏡：**R35 mm**、指定輪郭の幅39.805 ×高さ29.570 mm、厚さ1.5 mm。特注の前面反射光学鏡を想定。
- 光路：レンズ → 下部の平面鏡 → 凸球面鏡 → 顔。鏡1枚での頭内配置は投射距離が短いため、折り返しを追加しました。曲面鏡の合焦を保証するものではありません。

## 実機との区別

TI公称の投射比1.2、オフセット100%、1280×720を使用しています。[ユーザーガイド](https://www.ti.com/lit/ug/dlpu058a/dlpu058a.pdf)

実機の評価キットは光学エンジンだけではありません。TI公式の組立図では一式の外接寸法が135.00 ×81.34 ×49.82 mmです。この一式や分離配置した基板・ファンの収納を、現在の概形検証から推定していません。[TI組立図](https://www.ti.com/lit/pdf/TIDRUZ8)・[公式CAD配布ページ](https://www.ti.com/tool/TIDA-01571)

**ピント・収差・歪み補正・放熱・配線・支持部は未検証**です。UIの代表画素光線では約92.7%が鏡を外れ、約5.4%が顔へ到達します。全面へ光が届いても、光の利用効率や実際の明るさが十分とは限りません。専用鏡を発注する前に実レンズでの光学検証が必要です。

内部Boolean面には微小な交差6組（最大線分長0.005338 mm）が残ります。両シェルは閉じた各1成分ですが、製造前に整理と肉厚・公差の確認が必要です。
